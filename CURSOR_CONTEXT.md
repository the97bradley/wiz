## Sync workflow

Script: `./scripts/sync-wiz-sec.sh`

Requirements:

- `gh` (GitHub CLI) with API access to list `orgs/wiz-sec/repos`
- network + `git`

Behavior:

1. Lists **all public** repos in `wiz-sec` (including **archived**)
2. Adds missing repos as submodules under `wiz-sec/<name>` tracking each repo’s **default branch**
3. Updates existing submodules to `origin/<default_branch>` tip
4. Rewrites `wiz-sec/SYNC_STATUS.md`
5. Warns (does not delete) if a local submodule no longer exists upstream

After sync, agents should:

```bash
./scripts/sync-wiz-sec.sh
git add wiz-sec .gitmodules
git commit -m "Sync wiz-sec repos"
git push origin main   # when user wants main; otherwise follow branch/PR policy for the session
```

Env override: `WIZ_SEC_ORG` (default `wiz-sec`) if mirroring a different org name.

## Technical notes

- Submodules are recorded in `.gitmodules` with explicit `branch = …` so `git submodule update --remote` tracks the right tip.
- `azure-sdk-for-go` is large; expect longer clone/fetch times.
- Nested `.git` dirs belong to submodules; do not vendor their contents into the parent tree.
- Org listing via `gh api orgs/wiz-sec/repos --paginate` (public API; no special org membership required for public repos).
